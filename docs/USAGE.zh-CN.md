# Snapshot 完整使用指南

## 1. 安装与启动

1. 打开项目的 [Releases 页面](https://github.com/wongzijie/Snapshot/releases/latest)。
2. 下载 `Snapshot-v1.0.0-win-x64.zip`。
3. 将 ZIP 解压到任意可写目录。
4. 双击 `Snapshot.exe`。

Snapshot 不显示常规主窗口。启动成功后，会在 Windows 系统托盘出现绿色截图图标。

发布包支持 Windows 10 版本 2004 或更高版本及 Windows 11 x64，并且是自包含版本，无需另行安装 .NET。

## 2. 两种截图模式

### 复制到剪贴板

默认按下：

```text
Ctrl + Alt + A
```

完成选区后，图片会直接进入 Windows 剪贴板。可在微信、Office、浏览器、设计软件或其他支持图片的应用中按 `Ctrl + V` 粘贴。

### 直接保存 JPG

默认按下：

```text
Ctrl + Alt + S
```

完成选区后，图片会直接保存为 JPG，不显示保存对话框。默认目录是 Windows 系统的“下载”文件夹。

文件名示例：

```text
Screenshot_2026-07-31_13-01-34-136.jpg
```

## 3. 选择截图内容

### 选择整个窗口

移动鼠标时，绿色边框会自动吸附鼠标下方的可见窗口。单击左键即可锁定该窗口。

Snapshot 会忽略透明、不可激活的系统悬浮层，减少状态栏、提示气泡等覆盖窗口被误选的情况。

### 创建自定义选区

在任意位置按住鼠标左键并拖动，松开后即可获得自定义矩形选区。

选区左上角会显示当前宽度与高度。

### 调整选区

选区锁定后：

- 拖动选区内部：移动整个选区。
- 拖动边缘：单方向缩放。
- 拖动角点：同时调整宽度和高度。
- 点击“重选”或按 `R`：重新选择。

## 4. 完成或取消

### 截图标注工具

锁定选区后，工具栏提供：

- **画笔**：拖动自由绘制；快捷键 `P`
- **箭头**：从起点拖到终点；快捷键 `A`
- **文字**：选择后单击截图任意位置，直接在出现的文本框中输入；快捷键 `T`
- **马赛克**：在需要隐藏的位置拖动；快捷键 `M`
- **颜色**：画笔/箭头使用红、黄、绿、蓝、白色板；文字模式下改变文字颜色
- **粗细 / 字号**：画笔、箭头模式下切换线宽；文字模式下循环切换常用字号
- **字体**：文字模式下打开系统字体选择器，可设置字体、字形、字号及任意颜色
- **撤销 / 重做**：工具栏按钮，或 `Ctrl + Z` / `Ctrl + Y`

文字编辑框没有背景填充，输入时可以直接看到图片背景和文字的真实落点，只使用绿色虚线表示当前编辑范围。

文字输入时可自然换行。按 `Ctrl + Enter` 完成当前文本框，按 `Esc` 放弃当前文本框；单击画布中的另一个位置会完成当前文字并立即创建下一个文本框。截图最终只保存文字本身，不会保留编辑框边框。

已经完成的文字仍是独立对象。在文字工具处于选中状态时：

- 单击已有文字：再次打开该文字框，可修改内容、字体、字号、字形和颜色。
- 在文字正文中按住并拖动：框选一个或多个字符；直接输入可替换选中的文字。
- 拖动绿色虚线边框：将整个文字对象自由移动到选区中的其他位置。
- 完成二次编辑后使用 `Ctrl + Z`：撤销本次内容、样式或位置修改。

第一次添加标注后，选区尺寸会固定，避免标注错位。如需改变截图范围，请点击“重选”或按 `R`；这会清除当前标注。

### OCR

选好区域后点击 `OCR`。Snapshot 使用 Windows 本机 OCR 引擎提取文字，并在独立结果窗口中显示和复制内容。OCR 不会上传图片。

默认使用 Windows 首选语言。也可以在设置中选择某个已安装的 OCR 语言。若列表里没有需要的语言，请先在 Windows 的“设置 → 时间和语言 → 语言和区域”中安装相应语言包。

### 内容翻译

点击“翻译”后，Snapshot 会先在本机执行 OCR，并保留每一行文字在截图中的位置；随后把识别出的文字发送给用户配置的 Microsoft Translator。程序会估算文字周围的背景颜色、遮盖原文，再自动缩放译文并绘制回对应位置，最后打开完整译图预览。

译图预览提供：

- **复制图片**：把整张译图放入剪贴板。
- **保存 JPG**：保存到当前截图保存目录，默认是系统“下载”文件夹。
- **关闭**：不保存译图并关闭预览。

纯色或较平坦的界面背景通常效果最佳。照片、渐变、纹理或文字互相重叠时，背景修补是近似效果，建议在预览中确认后再复制或保存。

首次使用前：

1. 双击托盘图标，打开 Snapshot 设置。
2. 在“OCR 与内容翻译”中选择目标语言。
3. 填写 Microsoft Translator 密钥。
4. 如 Azure 资源要求，填写区域；服务地址通常保持默认值。
5. 点击“保存设置”。

密钥会通过 Windows DPAPI 绑定当前 Windows 用户加密保存。Snapshot 不会把密钥写入日志。

完成截图：

- 按 `Enter`
- 按空格键
- 双击选区
- 点击绿色“复制”或“保存 JPG”按钮

取消截图：

- 按 `Esc`
- 单击鼠标右键
- 点击“取消”

## 5. 修改设置

双击系统托盘中的 Snapshot 图标，或右键后选择“设置…”。

### 修改快捷键

1. 点击要修改的快捷键输入框。
2. 按下新的组合键。
3. 点击“保存设置”。

快捷键必须：

- 包含至少一个修饰键：`Ctrl`、`Alt`、`Shift` 或 `Win`
- 再包含一个普通按键
- 两种截图模式不能使用相同组合

如果快捷键已被其他软件占用，Snapshot 会提示冲突，并保留此前可用的设置。

### 修改保存目录

在“保存目录”中输入路径，或点击“浏览…”选择文件夹。

托盘菜单中的“打开截图保存文件夹”可以快速打开当前目录。

### 修改 JPG 质量

质量范围为 60%–100%，默认 92%。质量越高，细节保留越多，文件也越大。

### 修改 OCR 与翻译

- “OCR 识别语言”来自 Windows 当前已安装的 OCR 语言包。
- “翻译目标语言”决定译图中回绘文字的语言。
- Microsoft Translator 密钥、区域和服务地址只用于主动点击“翻译”的请求。

## 6. 设置与日志位置

设置文件：

```text
%AppData%\Snapshot\settings.json
```

诊断日志：

```text
%LocalAppData%\Snapshot\Snapshot.log
```

日志不会保存截图内容、剪贴板数据、窗口标题或个人文件内容。

## 7. 常见问题

### 按快捷键没有反应

打开设置并重新保存快捷键。如果提示被占用，请更换组合键。微信、QQ、显卡工具及其他截图软件可能注册了相同快捷键。

### 找不到程序窗口

Snapshot 启动后常驻系统托盘，不显示主窗口。请在任务栏右下角的托盘区域中查找绿色图标。

### Windows 显示“未知发布者”

当前版本尚未进行商业代码签名。可在 Release 页面核对 SHA-256，或从公开源码自行构建。

### JPG 没有出现在“下载”文件夹

检查设置中的保存目录。Windows 的“下载”已通过系统 Known Folder API 获取，因此可能不是字面上的 `C:\Users\用户名\Downloads`。

### 如何退出

右键系统托盘图标，选择“退出 Snapshot”。

### OCR 提示没有可用语言

在 Windows 的“语言和区域”中安装所需语言及其语言包，然后重新打开 Snapshot 设置。OCR 依赖操作系统已经安装的识别语言。

### 翻译提示 401、403 或区域错误

检查 Microsoft Translator 密钥是否有效，以及“区域”是否与 Azure 资源一致。OCR 已经在本机完成，翻译失败不会丢失识别出的原文。

## 8. 隐私

- 截图、画笔、箭头、文字、马赛克和 OCR 全部在本机完成。
- Snapshot 不上传截图图片，不需要 Snapshot 账户，也不收集遥测。
- 只有用户主动点击“翻译”时，OCR 识别出的文字才会发送给设置中的 Microsoft Translator 地址。
- Translator 密钥使用当前 Windows 用户的 DPAPI 加密保存。
- 日志不包含截图、OCR 正文、翻译正文、密钥或剪贴板内容。
- Snapshot 不读取截图区域之外的个人文件。
