# Snapshot 完整使用指南

## 1. 安装与启动

1. 打开项目的 [Releases 页面](https://github.com/wongzijie/Snapshot/releases/latest)。
2. 下载 `Snapshot-v1.0.0-win-x64.zip`。
3. 将 ZIP 解压到任意可写目录。
4. 双击 `Snapshot.exe`。

Snapshot 不显示常规主窗口。启动成功后，会在 Windows 系统托盘出现绿色截图图标。

发布包为 Windows x64 自包含版本，无需另行安装 .NET。

## 2. 两种截图模式

### 复制到剪贴板

默认按下：

```text
Ctrl + Alt + A
```

完成选区后，图片会直接进入 Windows 剪贴板。可在微信、Office、浏览器、设计软件或其他支持图片的应用中按 `Ctrl + V` 粘贴。

### 直接保存 JPG

默认按下：

```text
Ctrl + Alt + S
```

完成选区后，图片会直接保存为 JPG，不显示保存对话框。默认目录是 Windows 系统的“下载”文件夹。

文件名示例：

```text
Screenshot_2026-07-31_13-01-34-136.jpg
```

## 3. 选择截图内容

### 选择整个窗口

移动鼠标时，绿色边框会自动吸附鼠标下方的可见窗口。单击左键即可锁定该窗口。

Snapshot 会忽略透明、不可激活的系统悬浮层，减少状态栏、提示气泡等覆盖窗口被误选的情况。

### 创建自定义选区

在任意位置按住鼠标左键并拖动，松开后即可获得自定义矩形选区。

选区左上角会显示当前宽度与高度。

### 调整选区

选区锁定后：

- 拖动选区内部：移动整个选区。
- 拖动边缘：单方向缩放。
- 拖动角点：同时调整宽度和高度。
- 点击“重选”或按 `R`：重新选择。

## 4. 完成或取消

完成截图：

- 按 `Enter`
- 按空格键
- 双击选区
- 点击绿色“复制”或“保存 JPG”按钮

取消截图：

- 按 `Esc`
- 单击鼠标右键
- 点击“取消”

## 5. 修改设置

双击系统托盘中的 Snapshot 图标，或右键后选择“设置…”。

### 修改快捷键

1. 点击要修改的快捷键输入框。
2. 按下新的组合键。
3. 点击“保存设置”。

快捷键必须：

- 包含至少一个修饰键：`Ctrl`、`Alt`、`Shift` 或 `Win`
- 再包含一个普通按键
- 两种截图模式不能使用相同组合

如果快捷键已被其他软件占用，Snapshot 会提示冲突，并保留此前可用的设置。

### 修改保存目录

在“保存目录”中输入路径，或点击“浏览…”选择文件夹。

托盘菜单中的“打开截图保存文件夹”可以快速打开当前目录。

### 修改 JPG 质量

质量范围为 60%–100%，默认 92%。质量越高，细节保留越多，文件也越大。

## 6. 设置与日志位置

设置文件：

```text
%AppData%\Snapshot\settings.json
```

诊断日志：

```text
%LocalAppData%\Snapshot\Snapshot.log
```

日志不会保存截图内容、剪贴板数据、窗口标题或个人文件内容。

## 7. 常见问题

### 按快捷键没有反应

打开设置并重新保存快捷键。如果提示被占用，请更换组合键。微信、QQ、显卡工具及其他截图软件可能注册了相同快捷键。

### 找不到程序窗口

Snapshot 启动后常驻系统托盘，不显示主窗口。请在任务栏右下角的托盘区域中查找绿色图标。

### Windows 显示“未知发布者”

当前版本尚未进行商业代码签名。可在 Release 页面核对 SHA-256，或从公开源码自行构建。

### JPG 没有出现在“下载”文件夹

检查设置中的保存目录。Windows 的“下载”已通过系统 Known Folder API 获取，因此可能不是字面上的 `C:\Users\用户名\Downloads`。

### 如何退出

右键系统托盘图标，选择“退出 Snapshot”。

## 8. 隐私

Snapshot 完全在本机处理图像：

- 不上传截图
- 不需要登录
- 不使用云端 API
- 不收集遥测
- 不读取截图区域之外的文件
