# Snapshot v1.0.0

Snapshot 的第一个公开版本。

## 下载与运行

1. 下载 `Snapshot-v1.0.0-win-x64.zip`。
2. 解压 ZIP。
3. 双击 `Snapshot.exe`。

这是 Windows x64 自包含版本，不需要单独安装 .NET。

## 默认快捷键

- `Ctrl + Alt + A`：截图并复制到剪贴板
- `Ctrl + Alt + S`：截图并直接保存为 JPG

## 主要功能

- 智能识别鼠标下方窗口
- 自定义矩形截图区域
- 选区移动和缩放
- 剪贴板快捷输出
- Downloads 文件夹 JPG 直存
- 可配置快捷键、保存目录与 JPG 质量
- 系统托盘常驻
- 完全离线，无账户、上传和遥测

## 系统要求

- Windows 10/11
- x64

## 已知限制

- 当前尚未进行商业代码签名
- 暂不包含画笔、箭头、文字、马赛克、OCR 或截图贴图

完整操作方法请参阅仓库中的 [使用指南](../USAGE.zh-CN.md)。
